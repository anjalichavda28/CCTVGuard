About CCTVGuard

Smart CCTV Monitoring System

CCTVGuard is a web-based CCTV monitoring system designed to provide a simple and user-friendly security monitoring interface.

Project Features

  • Camera monitoring
  • Camera status tracking
  • Security alerts
  • Activity monitoring
  • Dashboard overview
  • System settings

Technology Used
