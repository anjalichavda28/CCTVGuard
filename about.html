About CCTVGuard

Project Objective

CCTVGuard is a simple CCTV monitoring interface to organize camera information, alerts and activity in one place.

Key Modules

  • Dashboard and camera summary
  • Camera list with search and status
  • Security alerts and activity timeline
  • Demo login and settings page

Technology Used

HTML, CSS and JavaScript.

This is a frontend college project prototype. It does not connect to real CCTV hardware or perform live AI detection.
